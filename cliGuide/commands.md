# Essential Git CLI Commands

## 1. `git status`
Shows which files have been modified, which are staged for commit, and which branch you're on. A good habit before every `git add` or `git commit`.

## 2. `git checkout -b <branch-name>`
Creates a new branch and switches to it in one step. Used to work on a feature separately without affecting `main`.

## 3. `git push origin <branch-name>`
Uploads your local commits on a branch to GitHub, so others can see them and you can open a Pull Request.
